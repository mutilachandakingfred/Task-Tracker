# Task-Tracker
This is a repository that starts off as a CLI that is used to track what is to be done. It allows a user to 1. add, update, and delete tasks. 2. to mark the tasks as in progress or done. 3. to list all tasks. 4. to list all the tasks that are done 5. to list all the tasks that are not done. and finally, to list all the tasks that are in progress.
